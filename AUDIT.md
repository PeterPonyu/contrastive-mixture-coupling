# Paired-state and contrastive-invariant audit

The saved-result checks cover six endpoints, paired batch orders, mixture-refit subsets, responsibility reconstruction and endpoint contrasts. Maximum probability-reconstruction error was 2.53e-7 or smaller in the tested environment. Synthetic frozen-code probes check initial query/key equality, queue and momentum updates, normalization calls and contrastive coefficient behavior with zero optimizer updates.

The separate checkpoint audit verifies twelve file digests and saved warmup/state identities. These checks require this study's checkpoint archive; the default small-input analyses and figure generation do not. Numerical robustness results are reproduced without altering the saved checkpoints.

The initialization probe exposes unsynchronized query/key states. Shared implementation behavior in paired arms does not itself invalidate a coupling contrast, but it limits claims about contrastive learning more broadly. Three paired seeds on one fixed biological background are not a population-level effect estimate. A complete raw-data training and scoring pipeline is not included.

## Verification boundary

The README specifies the commands and tested dependencies. `release-manifest.json` identifies the distributed files; historical producer hashes identify their original computations. All manuscript pages were rendered and programmatically checked for layout candidates. This is not a human visual sign-off. Scientific scope and known limitations are retained even when computational checks pass.
